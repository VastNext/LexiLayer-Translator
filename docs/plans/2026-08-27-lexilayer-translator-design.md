# LexiLayer Translator Chrome Plugin 设计

## 目标

开发一个性能优先的 Chrome Manifest V3 双语网页翻译插件。0.4.2 使用 Google 作为默认免费引擎、Bing 作为备用引擎，并允许最多 20 个自定义 AI 实例。MVP 支持网页翻译、双语/仅译文/恢复原文、现代 SPA 可见文本叶、动态页面、统一三点星座图标、可拖动划词翻译、选区内联翻译、缓存、重试、右键菜单和 `Alt+A` 快捷键。

## 独立实现边界

项目只参考原插件的可观察行为和通用架构思想，不复制其压缩源码、品牌、接口、文案或视觉资产。原插件 1.32.6 闭源发行包中的 769 条站点规则仅导出到 Git 忽略的 `research/private-reference/`，作为未来重新观察站点和原创规则的研究索引；这些资料不得进入源码、构建产物、提交或远端仓库。

站点适配采用原创规则引擎。首版只为高频站点编写少量原创规则，未命中时使用通用语义 DOM 扫描。轻量 URL 索引常驻，规则详情按域名动态加载。

## 架构

- Manifest V3 service worker：持有配置和 API Key，调用 OpenAI 兼容接口，执行重试、流解析、缓存与浏览器命令。
- 原生 TypeScript content script：按需扫描 DOM、调度可见段落、插入译文、监听动态内容，并用 Shadow DOM 实现划词浮层。
- React Popup：控制当前页面翻译状态、语言、显示模式、翻译范围和失败重试。
- React 设置页：启停并选择固定 Google/Bing，管理多个自定义 AI 的连接、密钥、默认项和排序，以及阅读偏好、缓存和带确认的配置导入导出。
- IndexedDB：缓存成功译文；API Key 不进入缓存。

API Key 按自定义实例保存在 `chrome.storage.local`，Options 仅通过专用受信消息读取，密钥不发送给 content script、不记录日志。导出时由用户明确选择是否包含密钥；导入可信的含密钥文件会直接恢复本地密钥。后台不暴露任意 URL fetch；连接测试只接受内置项或完整候选实例，不构成通用代理。

## 权限

安装时申请 `<all_urls>`，用于普通网页内容脚本和用户自定义 API 地址。MVP 只使用 `storage`、`contextMenus` 和必要的网页宿主权限，不申请 webRequest、DNR、offscreen 或 sidePanel。

## 翻译数据流

内容脚本创建带 ID、源文本哈希和 DOM 版本的段落实体，优先翻译可见区域。每批最多 8 段、约 6000 字符，默认并发 3。后台通过 `/chat/completions` 请求带 ID 的 JSON 翻译结果，验证响应后返回纯文本。回填前再次检查任务 ID、节点连接状态和 DOM 版本，拒绝陈旧结果。

Google/Bing 网页与划词翻译均使用非流式响应；自定义 AI 网页翻译使用非流式 JSON，划词翻译优先使用 Chat Completions SSE 流，服务不支持时回退到非流式。429 和 5xx 最多重试两次，尊重 `Retry-After`；Google 429 会提示稍后重试或切换 Bing。默认超时 45 秒。

v2 导入先验证无密钥、无危险字段、无重复 ID 和无保留 ID 伪装，再合并本地密钥。只有相同 ID 与相同 Origin 的自定义实例继承密钥；Origin 变化会清空密钥。旧版单实例配置首次读取时迁移为自定义 AI，默认引擎设为 Google。

## DOM 与动态页面

通用扫描翻译标题、段落、列表、引用、图注和表格单元格，跳过脚本、样式、代码、导航、按钮、表单、隐藏元素、contenteditable 和插件自身节点。译文以纯文本 wrapper 插在原元素前或后，不执行模型返回的 HTML。

`IntersectionObserver` 负责滚动附近段落，`MutationObserver` 只批量扫描新增子树。原文变化会提高段落版本并使旧译文失效。插件节点统一标记，避免观察器自触发。

## 语言与交互

首次默认目标语言由 `chrome.i18n.getUILanguage()` 映射，无法识别时回退英语。页面语言与目标语言相同时，目标为英语；若目标已是英语，则改为简体中文。

Popup 支持翻译/恢复、进度、源/目标语言、双语/仅译文、主要内容/整个页面和失败重试。划词后显示原创 V 形按钮，点击打开隔离浮层，支持流式译文、复制、重试、目标语言切换和关闭。选区最大 5000 字符，输入框和 contenteditable 不处理。

## 缓存与隐私

缓存键包含规范化原文、源/目标语言、Base URL 摘要、模型、内置提示词版本和用户要求摘要。缓存默认保留 30 天、最多 5000 条，只保存完整成功结果。无遥测、账户、广告、远程配置或云同步；网页文本只发送到用户配置的 API 服务。

## 验证

Vitest/jsdom 覆盖配置、URL、语言映射、批处理、JSON/SSE 解析、缓存键、DOM 提取与回填、动态去重和规则匹配。Playwright/Chrome 实机验证构建加载、设置、网页翻译、动态内容、划词、快捷键、右键菜单和错误路径。构建检查入口体积，确保未启用翻译时不扫描页面或加载站点规则详情。

## 交付

项目位于仓库根目录，使用独立 Git 仓库。完成验证后创建私有仓库 `VastNext/VastTranslatorChromePlugin` 并推送 `main`。暂不添加开源许可证。
