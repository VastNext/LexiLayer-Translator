# 局部重试与完整重置修复

## 已定位的路径

0.10.7 的 retryFailed 只收集失败项，却调用 beginSession 作废整个代际、停止所有可见性队列并取消整页任务。失败项重试后，其余在途或屏外等待项未被重新接管，仍显示 loading。

## 执行范围

- 局部重试保留当前 generation、后台任务、动态观察器和未完成队列。
- 重试候选同步退出 failedIds；仅再次失败时加回，避免连续点击和离屏 whenIdle 提前返回造成重复队列，不使用跨会话全局锁。
- 恢复原文、新翻译与销毁的本地处理不等待后台取消返回；取消拒绝被捕获，旧结果通过代际隔离。
- 保留成功译文缓存，重新翻译只对未命中部分发送请求。

## 验收要求

1. 成功 A、失败 B、在途 C、离屏 D 同时存在，重试 B 不取消 C/D；C 返回、D 可见后正常结束。
2. 离屏失败项进入重试后，再次重试不重复提交；再次失败后可再次重试。
3. 旧重试悬挂时恢复并开启新会话，新会话可正常重试。
4. 后台取消拒绝或永不返回，本地恢复立即完成，旧结果不能写回。
5. 本地浏览器验证重试、滚动、恢复、重新翻译及请求计数，缓存命中不重复调用 AI。

不修改扫描器、渲染器、缓存策略、超时配置或52 KiB累计门禁。现场Vercel全部触发路径未经过独立在线验证，不据此作全站兼容承诺。

## 缓存与取消边界

缓存键由文本、语言、引擎身份与提示词等语义配置构成，不包含页面 taskId，因此完整重置可复用成功译文。后台任务取消按标签页、frame、document 和 taskId 隔离；AI 去重请求可能由多个任务共同订阅，取消旧任务只释放其订阅。取消通信失败时不能保证底层请求立即停止，可能继续消耗服务配额，但本地恢复与旧结果隔离不应因此阻塞。
