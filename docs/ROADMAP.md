# 下一阶段功能想法

> 简单记录后面要实现的功能，防止忘记。每项实施前再写正式的设计与实现计划。

- **快捷键设置**：开放自定义快捷键，不再写死固定按键（如当前划词/翻译的触发键）。
- **朗读单词**：为划词结果和生词提供发音朗读（TTS）。
- **生词本管理**：划词时可一键加入生词；加词时尽量把单词所在的整句一起记录，复习时关联展示当时的句子和出处。
- **术语库管理**：用户维护术语表，翻译时优先应用，保证专有名词译法一致。
- **翻译网站**：在 vastnext.com 上承载文本翻译，并可尝试 PDF 翻译；注意与「不运营接收翻译内容的自营服务器」边界的冲突——优先纯客户端调用，否则先修订边界再立项。
- **PDF 翻译（扩展侧）**：支持浏览器内置 PDF 查看器里的正文翻译。
- **YouTube / B站字幕翻译**：为 YouTube 和 Bilibili 视频提供字幕翻译。
- **图片 OCR 翻译**：识别网页图片中的文字并翻译。
- **Token 节省优化**：审视提示词长度、上下文裁剪、缓存命中和批量合并策略，降低 AI 翻译的 Token 消耗。
- **自动整站翻译**：用户发起一次后，站内导航时自动延续翻译。
- **多专家串联与专家组合收藏**：多个专家提示词按序组合，并可保存常用组合。
- **站点级专家自动选择**：按站点记忆/推荐适用的 AI 专家，免于逐页手动切换。
- **专家目录运行时更新**：保持离线优先，提供从专家仓库拉取新快照的受控更新。
- **加密备份文件**：含 API Key 的配置导出提供加密格式，降低误分享风险。
- **账号同步 / 云端配置**：与「不运营自营服务器」的边界冲突，做之前必须先重新评估隐私边界和披露。
