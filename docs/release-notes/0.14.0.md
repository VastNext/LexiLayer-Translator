# 语层翻译（LexiLayer Translator）0.14.0

## 划词朗读与生词本

- 划词面板底部新增 🔊 朗读按钮：使用浏览器本机语音（Web Speech API）朗读选中的原文，不发网络请求；再次点击停止，关闭面板或开始新选区自动取消。
- 划词面板新增 📓 加入生词按钮：一键把当前选词写入本地生词本，并尽量记录单词所在的完整句子、当时的译文、出处页面 URL 与标题。
- 同词同句视为重复加词并刷新原条目；同词不同句允许并存，保留不同语境。加入成功、重复与失败都会在面板上即时反馈。
- 生词数据（含状态版本）保存在 `chrome.storage.local` 的 `vocabularyBook`，只在本机使用；选区位于输入框或富文本编辑控件内时不记录。

## 生词本管理（设置页）

- 设置页新增「生词本」栏目：列表支持按单词与例句搜索、查看出处链接、逐条删除（双击确认）与清空（双击确认）。
- 内置复习模式：顺序卡片展示单词，展开后关联当时的整句、译文、出处与朗读。
- 支持朗读每条生词（本机语音），以及 JSON（含出处时两步确认）、CSV、TSV 文件导出，便于备份或导入其他工具。

## AnkiConnect 同步（本机与远程）

- 在设置中配置 AnkiConnect 兼容端点后，可执行连接测试与一键同步：自动校验/创建 deck，按 deck 去重推送，返回新增、跳过与失败统计。
- 支持本机回环端点（`127.0.0.1`、`localhost`、`[::1]` 可用 HTTP）与远程端点（必须 HTTPS，兼容自定义端口与路径，拒绝 URL 内嵌凭据）。
- 支持 AnkiConnect 标准 API Key：密钥仅保存在本地，只随请求体 `key` 字段发往该端点，不返回网页、不写入错误消息；远程端点未配置密钥时显示安全警告并需确认。
- Basic 与 Cloze 两种笔记模板可选；每批最多 50 条。未配置端点时仍可使用 CSV/TSV 文件导入 Anki。

## 兼容与隐私

- manifest 权限不变：朗读无需新权限，本机与远程 Anki 请求复用既有 host permission。
- 新增 `selection-features.js` 常驻内容脚本承载划词新动作，与既有页面翻译三脚本分离并受独立体积预算约束；后台新增生词/Anki 逻辑拆分为独立模块分片。
- 生词仅在用户主动同步时发送到其配置的 AnkiConnect 端点；语层翻译不设中转服务器。远程 Anki 服务的日志、保留策略与后续 AnkiWeb 同步由该服务与用户配置决定。
- 旧配置自动补齐生词本默认值；配置导入导出的密钥边界保持不变，Anki 密钥仅随「包含 API Key」导出写入。

## 安装与升级

1. 下载本 Release 中的 `lexilayer-translator-0.14.0-chrome-web-store.zip` 并解压。
2. 在 `chrome://extensions/` 开启开发者模式，选择解压后的目录完成加载或重新加载。
3. 确认版本为 **0.14.0**，并刷新已打开网页以加载新版内容脚本。
