# 语层翻译（LexiLayer Translator）0.11.0

## 🗂️ 自定义 AI 与专家体验优化

本次更新优化了自定义 AI 卡片的折叠与新建交互，新增取消操作并清理冗余视觉元素。

## 🛠️ 改进与优化

- 🗂️ **自定义 AI 卡片默认收起**：已保存的自定义 AI 实例默认收起展示，支持点击整张卡片标题或折叠图标展开/收起，并放大折叠按钮点击区域。
- ✏️ **新建表单占位提示化**：自定义 AI 与自定义专家新建表单不再预填真实文本，改为占位提示（聚焦输入即消失），无需手动退格删除。
- ↩️ **新增取消与取消编辑**：自定义 AI 卡片新增取消按钮，新建草稿一键移除、已保存实例一键重载还原。
- 🏷️ **移除冗余徽标**：清理自定义 AI 卡片顶部冗余的“AI”徽标，使卡片头部更清爽。

## ✅ 验证

- 全量单测与 Options UI 用例通过。
- 静态类型检查与生产构建体积通过。

## 📦 安装与升级

1. 下载本 Release 中的 `lexilayer-translator-0.11.0-chrome-web-store.zip` 并解压。
2. 在 `chrome://extensions/` 开启开发者模式，选择解压后的目录完成加载或重新加载。
3. 确认版本为 **0.11.0** 即可。
