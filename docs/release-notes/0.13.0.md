# 语层翻译（LexiLayer Translator）0.13.0

## 输入框选区翻译

在支持的普通 input、textarea 或 contenteditable 中选中文字，按 `Alt+Shift+X`，使用当前翻译引擎仅替换选中部分，无需先翻译网页。

输入框目标语言独立于网页目标语言，默认英语，可在设置的阅读偏好中修改。旧配置读取和导入时自动补齐默认值。自定义 AI 沿用当前专家和翻译要求。

## 安全与兼容

- 只发送选中文字，最多 5000 字符，不附带输入框其余文本或邻近上下文。
- 密码、只读和禁用控件不处理；中文输入法组合期间不触发，在途重复按键不重复请求。
- 失败保留原文；内容、选区或焦点变化时放弃回填。译文按纯文本插入。
- 可获取标准选区的 input 类型为 text、search、url、tel。支持普通富文本，不保证复杂编辑器内部状态和撤销历史兼容。
- 独立轻量脚本在已获权限的普通网页与同源/跨源 HTTP(S) frame 内运行，不扫描正文。跨 frame 选区、Shadow DOM、about:blank/srcdoc/data/blob frame 和浏览器受限页面不支持。
- 安装或更新扩展后，请刷新已打开的网页。

## ⌨️ 快捷键与触发方式

本次更新在设置页新增统一的“快捷键与触发方式”栏目，明确区分由浏览器管理的页面翻译快捷键和由扩展管理的选区内联触发。

## ✨ 新功能与改进

- **显示真实页面快捷键**：Options 与 Popup 读取浏览器 `commands` 状态，展示当前实际绑定；未分配或暂时不可读取时不再回退显示固定按键。
- **跳转浏览器管理页**：设置页可打开浏览器原生快捷键管理页。扩展只读取状态，不会自动重绑或清空 Chrome 内部快捷键。
- **统一选区触发设置**：修饰键和单击、双击、三击设置迁移到新栏目，并说明输入区域排除及再次触发移除译文的行为。
- **更安全的新安装默认值**：新安装默认双击 `Ctrl`，单次按键不会触发，减少与 `Ctrl+C`、`Ctrl+V` 等组合键冲突的风险。
- **保留旧用户行为**：旧用户、旧版配置迁移和旧导入配置不会被新默认值覆盖，已有触发次数保持不变。
- **两种划词入口独立**：关闭 V 形划词悬浮按钮后，已启用的键盘内联触发仍然可用。
- **稳定无障碍名称**：Popup 页面翻译按钮使用稳定动作名称，动态快捷键作为独立辅助信息展示。

## 📦 安装与升级

1. 下载本 Release 中的 `lexilayer-translator-0.13.0-chrome-web-store.zip` 并解压。
2. 在 `chrome://extensions/` 开启开发者模式，选择解压后的目录完成加载或重新加载。
3. 确认版本为 **0.13.0** 即可。
