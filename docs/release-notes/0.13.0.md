# 语层翻译（LexiLayer Translator）0.13.0

## 输入框选区翻译

在支持的普通 input、textarea 或 contenteditable 中选中文字，按 `Alt+Shift+X`，使用当前翻译引擎仅替换选中部分，无需先翻译网页。

输入框目标语言独立于网页目标语言，默认英语，可在设置的阅读偏好中修改。旧配置读取和导入时自动补齐默认值。自定义 AI 沿用当前专家和翻译要求。

## 安全与兼容

- 只发送选中文字，最多 5000 字符，不附带输入框其余文本或邻近上下文。
- 密码、只读和禁用控件不处理；中文输入法组合期间不触发，在途重复按键不重复请求。
- 失败保留原文；内容、选区或焦点变化时放弃回填。译文按纯文本插入。
- 可获取标准选区的 input 类型为 text、search、url、tel。支持普通富文本，不保证复杂编辑器内部状态和撤销历史兼容。
- 独立轻量脚本在已获权限的普通网页与同源/跨源 HTTP(S) frame 内运行，不扫描正文。跨 frame 选区、Shadow DOM、about:blank/srcdoc/data/blob frame 和浏览器受限页面不支持。
- 安装或更新扩展后，请刷新已打开的网页。
