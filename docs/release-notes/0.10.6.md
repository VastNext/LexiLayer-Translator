# 语层翻译（LexiLayer Translator）0.10.6

## 修复

- 清理动态网页移除或替换原文节点时残留的翻译占位，避免旧“翻译中…”失去管理。
- 进度广播在 Popup 无接收端时不再产生未处理的 Promise 拒绝；翻译结果通道保持独立。

## 范围说明

- 不强制排空屏外段落，不改变可见性懒加载策略。
- 尚未确认 Vercel 现场的两段异常一定由节点替换触发；本版本修复的是本地可复现的生命周期缺陷。
- 本次节点克隆回归针对兼容模式的相邻占位；内联模式深克隆同时复制插件子树的情况尚未纳入本次修复。
- 超时时间配置保留为独立后续需求；不改变权限、密钥存储和数据发送目的地。

## ✅ 验证

- 回归覆盖源节点替换后的占位清理、迟到结果隔离及进度广播拒绝。
- 发布前执行全量单测、类型检查、生产构建及本地扩展 E2E；不以本地测试替代 Vercel 现场验证。
