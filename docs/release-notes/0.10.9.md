# 语层翻译（LexiLayer Translator）0.10.9

## ⚡ 即改即存与体验优化

本次更新将阅读偏好与划词翻译栏目下的手动保存按钮统一移除，全面对齐现代软件设置逻辑。✨

## 🛠️ 改进与优化

- ⚙️ **自动防抖保存**：修改目标语言、显示模式、译文位置、渲染器模式、划词悬浮图标及快捷键等任意偏好项，失焦/防抖后自动异步持久化，无需手动翻找点击保存按钮。
- 🔄 **失败重试入口**：若遇到本地存储写入异常，状态条即时告警并提供「重试保存」快捷按钮，避免配置丢失。
- 🔒 **加载门禁防护**：配置尚未从存储完全读取时保持表单锁定，避免默认值瞬态覆盖已有设置。

## ✅ 验证

- 全量单测（含 Options UI 自动保存、防抖合并、失败恢复门禁）616 项全数通过。
- 静态类型检查与生产构建体积通过。
- 本地扩展 E2E 测试全部通过。

## 📦 安装与升级

1. 下载本 Release 中的 `lexilayer-translator-0.10.9-chrome-web-store.zip` 并解压。
2. 在 `chrome://extensions/` 开启开发者模式，选择解压后的目录完成加载或重新加载。
3. 确认版本为 **0.10.9** 即可享受即改即存的设置体验。
