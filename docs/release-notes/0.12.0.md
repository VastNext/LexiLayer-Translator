# 语层翻译（LexiLayer Translator）0.12.0

## 🗂️ 自定义 AI 卡片单行三段式布局

本次更新重构了自定义 AI 卡片的头部布局，将名称、模型与端点摘要、默认徽标以及启用开关合并至单行三段式，消除了收起态时的空白头部行。

## 🛠️ 改进与优化

- 🗂️ **单行三段式布局**：自定义 AI 卡片（收起态与展开态）统一使用单行三段式（折叠按钮与实例名称 + 模型/端点摘要 + 默认徽标 + 启用开关同行），信息展示更加紧凑清晰。
- 👁️ **模型与端点即时摘要**：无需展开卡片即可一览实例配置的模型名与 Base URL 来源；新建未填写内容时清晰显示“尚未配置”。
- 🛑 **开关交互隔离**：点击启用开关时精准拦截事件冒泡，不会误触发卡片的展开或折叠。
- 🧹 **收起态上下内边距收紧**：收紧收起态卡片内边距，移除冗余的独立头部行与废弃 CSS 类。

## ✅ 验证

- 全量单测与 Options UI 用例通过。
- 静态类型检查与生产构建体积通过。

## 📦 安装与升级

1. 下载本 Release 中的 `lexilayer-translator-0.12.0-chrome-web-store.zip` 并解压。
2. 在 `chrome://extensions/` 开启开发者模式，选择解压后的目录完成加载或重新加载。
3. 确认版本为 **0.12.0** 即可。
