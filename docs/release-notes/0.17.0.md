# 语层翻译（LexiLayer Translator）0.17.0

## Bilibili 双语字幕

- 在 bilibili.com 视频页自动读取站内字幕轨道（含 AI 字幕）并翻译为双语显示；译文行注入播放器字幕区域，全屏自动适配。
- 「AI 字幕」需登录 B 站：未登录时明确提示「登录 B 站后可读取 AI 字幕」，无字幕视频同样明确提示。
- 站内分 P 切换自动重建字幕会话；播放进度实时跟随；字幕点词同样可用。
- 数据流：扩展以页内带登录凭据的请求读取当前视频的字幕轨道（凭据仅发往 bilibili.com 自身），字幕文本按所选引擎翻译；接口细节不在公开仓库文档化。

## 字幕点词与生词本联动（YouTube + Bilibili）

- 点击字幕中的单词：弹出释义悬浮层，释义跟随当前翻译引擎（含自定义 AI），就绪前按钮禁用。
- 一键「加入生词本」：把单词、字幕整句、释义与出处（页面 URL + 标题）写入本地生词本；重复加入会提示「已在生词本」。
- 与 0.14.0 生词本管线无缝衔接：加入的字幕生词可在设置页复习、导出、同步 Anki。
- 悬浮层支持 Escape / 点击外部关闭；字幕词在原文行内高亮可点击。

## 兼容与隐私

- 无新增权限；新增两条仅匹配 bilibili.com 的内容脚本。
- Bilibili 登录凭据只发往 bilibili.com 自身；字幕文本与点词数据按所选引擎发送；加入生词本的数据仅存本地（用户主动同步时才发往其 AnkiConnect 端点）。PRIVACY 与商店数据披露已同步。
- 既有 YouTube 双语字幕行为不变。

## 安装与升级

1. 下载本 Release 中的 `lexilayer-translator-0.17.0-chrome-web-store.zip` 并解压。
2. 在 `chrome://extensions/` 开启开发者模式，选择解压后的目录完成加载或重新加载。
3. 确认版本为 **0.17.0**，并刷新已打开网页以加载新版内容脚本。
