# 语层翻译（LexiLayer Translator）0.7.3

## 🐞 Bug 修复

- 🗂️ **GitHub 仓库表格误翻**：整页翻译时排除仓库文件列表等数据表格，README 等正文仍可正常翻译。
- 📈 **Google Trends 数据区域误翻**：排除 Trends 页面中的数据表格，避免图表和指标区域被翻译覆盖。
- 🧹 **自定义 AI 译文顶部空行**：清理流式响应开头多余的换行，让划词译文直接从正文开始显示。
- ⏳ **划词翻译缺少状态提示**：发起划词翻译后立即显示“准备翻译…”，不再让用户误以为没有响应。
- 🚦 **划词内联翻译重复请求**：连续触发快捷键时取消当前等待结果，避免重复发送翻译请求；旧结果也不会在取消后插入页面。

- 单元测试：32 个测试文件、442 个测试通过。
- TypeScript 类型检查通过。
- 生产构建通过，`content.js` 与 `background.js` 体积预算通过。
