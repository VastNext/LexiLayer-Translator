- 🛑 **代码块标签栏与包管理器选项卡误翻**：在通用硬排除规则中加入 `[data-geist-code-block]`、`[data-section="tabs"]`、`[role="tablist"]`、`[role="tab"]` 等选择器，彻底避免技术文档（如 Vercel、Next.js 等文档）中的代码块切换栏（`pnpm / yarn / npm / bun`）与终端工具栏被当作正文翻译。
