# 语层翻译（LexiLayer Translator）0.13.2

## 表单内部说明性文本扫描修复

修复了在部分网站（如 SaaSHub 等产品提交页面）中，包裹在 `<form>` 容器内部的段落、说明、提示及列表文字被硬编码排除而无法被翻译的问题。

## 🐞 修复与改进

- **表单文本正常提取**：移除全局硬编码排除列表中的 `form` 标签，允许提取表单内的说明性段落（如 `<p>`, `<li>`, `<div>` 文本等）。
- **交互控件持续安全隔离**：继续严格排除 `input`, `textarea`, `select`, `button` 等输入控件与交互元素，保证表单交互不受干扰。
- **渲染兼顾**：确保表单内说明文本在内联或兼容渲染模式下均能正常渲染翻译。

## ⌨️ 快捷键与触发方式

继续沿用 0.13.0 快捷键架构，在设置页清晰展示浏览器管理的页面翻译快捷键和扩展管理的选区内联触发：
- 浏览器实际快捷键：设置页与 Popup 动态读取浏览器快捷键，支持跳转管理。
- 双击 Ctrl 触发：新安装默认双击 Ctrl 触发选区内联翻译，旧用户配置保留不覆盖。

## ✅ 验证

- 1000 段大页面在 loading 期间可以执行恢复并清理全部扩展节点。
- 内容脚本与后台 bundle 继续满足体积预算。
- 全量单元、UI、构建与契约测试通过。

版本统一来自 package.json，当前为 0.13.2。Chrome Web Store 公开隐私政策、素材、审核测试页与第三方端点许可等既有上架阻断项仍需发布者处理。

## 📦 安装与升级

1. 下载本 Release 中的 `lexilayer-translator-0.13.2-chrome-web-store.zip` 并解压。
2. 在 `chrome://extensions/` 开启开发者模式，选择解压后的目录完成加载或重新加载。
3. 确认版本为 **0.13.2** 即可。
