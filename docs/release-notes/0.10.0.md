# 语层翻译（LexiLayer Translator）0.10.0

## 新增与优化

- 自定义 AI 缓存未命中项在最多 100ms 的收集窗口内合批，保留 8 段／6000 字符上限；相同翻译身份的重复文本共享进行中结果，并映射回各调用者段落 ID。
- 取消仅撤销当前调用者订阅，仍有其他订阅者时不误取消共享请求；合法部分结果保留，失败项仍可重试。
- 后台内存计数可用于调试缓存命中、去重、provider 批次与字符量，不保存正文、URL、密钥或提示词，不上传。provider 调用数不等于底层 HTTP 次数，字符量不等于计费 Token。

## 修复

- 折叠按钮内部仅翻译安全文本叶，保留按钮、图标、点击与键盘交互，兼容内联和传统模式。
- `inert` 折叠区域不提前翻译或显示等待占位；展开后按可见性重新扫描，复选框与标签关联保持。
- 文本叶在动态重译期间保持连接，全页恢复时统一解包；已移除节点不再进入重译队列。
- 滚动后才发出的批次失败时即时显示错误和重试入口，不再永久停在“翻译中”。

## 边界

- Google/Bing 保持原有请求路径；自定义 AI 非流式划词也经过协调器，流式划词不经过。
- 合批和去重减少重复输入与生成，但不保证所有页面获得相同节省比例；本轮没有读取供应商 usage 或提供费用账单界面。
- 清缓存不取消当前翻译，在途请求完成后仍可能回写缓存。

## ✅ 验证

- 使用本地模拟 provider 验证冷缓存合批、热缓存零调用、重复文本去重、取消隔离与部分结果。
- DOM 单元测试和本地 Chromium 验证折叠按钮、仅译文图标、checkbox 与恢复。
- 最终验证结果以本次交付记录为准，不代表对用户私人 AI 接口进行了调用。
