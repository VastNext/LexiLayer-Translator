# 语层翻译（LexiLayer Translator）0.13.1

## 输入框翻译状态提示

- 在 input、textarea、contenteditable 及网页 frame 中使用 `Alt+Shift+X` 成功触发选区翻译后，会在当前编辑控件右上附近显示“翻译中…”和加载动画。
- 控件上方空间不足时，提示自动放到下方。提示使用 closed Shadow DOM 隔离网页样式，不写入或占用表单内容。
- 翻译完成、失败保留原文、内容或选区变化取消时，显示短暂终态后自动移除。
- 在途重复快捷键不会重复请求，并维持单实例提示；迟到旧任务不能覆盖新任务状态，脚本卸载时同步清理提示和计时器。

## 兼容与隐私

- 输入框翻译的数据处理行为不变：只发送用户选中的文字，不发送输入框其余内容或邻近上下文。
- 浏览器管理的页面翻译快捷键、默认双击 `Ctrl` 的选区内联触发和旧用户配置均保持不变，不会覆盖旧用户设置。

## ✅ 验证

- Vitest 覆盖加载、成功、失败、取消、重复按键、旧任务隔离、上下定位和 dispose 清理。
- Chromium E2E 覆盖真实扩展中的 closed Shadow DOM 状态、重复按键、失败保留原文及 frame 输入翻译。
- 继续运行单元测试、类型检查、生产构建、发布校验和完整 Chromium E2E 门禁。

## 📦 安装与升级

1. 下载本 Release 中的 `lexilayer-translator-0.13.1-chrome-web-store.zip` 并解压。
2. 在 `chrome://extensions/` 开启开发者模式，选择解压后的目录完成加载或重新加载。
3. 确认版本为 **0.13.1**，并刷新已打开的网页以加载新内容脚本。
