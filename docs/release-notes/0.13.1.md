# 语层翻译（LexiLayer Translator）0.13.1

## ⚡ Popup 与大页面响应性

本次修复降低网页初载和大页面翻译期间的连续主线程占用，并将“页面接受翻译命令”与“翻译任务完成”解耦，减少点击扩展图标或控制页面时长时间无反馈的情况。

## 🐞 修复与改进

- **翻译命令立即确认**：页面接收翻译命令后立即返回，Popup 不再等待 DOM 扫描、loading 安装或慢速翻译引擎完成。
- **尽早显示进度**：页面在扫描前先上报翻译状态，后续完成、失败与恢复继续由进度通道驱动。
- **大 DOM 协作式准备**：减少扫描阶段重复样式计算，并让 loading 安装和恢复清理按时间预算释放主线程，给浏览器绘制、Popup 创建和页面控制留出调度机会。
- **处理中可恢复**：loading 安装期间收到恢复命令时，旧任务停止继续写入，已安装节点分片清理。
- **Popup 初始化去重**：同一 Popup 生命周期只解析一次目标标签页，并使用单一的“实时订阅 + 初始快照”进度链路。
- **配置加载反馈**：Popup 配置较慢时显示加载状态；读取失败可原地重试，不会用 fallback 覆盖真实偏好。

## ⌨️ 快捷键与触发方式

继续沿用 0.13.0 快捷键架构，在设置页清晰展示浏览器管理的页面翻译快捷键和扩展管理的选区内联触发：
- 浏览器实际快捷键：设置页与 Popup 动态读取浏览器快捷键，支持跳转管理。
- 双击 Ctrl 触发：新安装默认双击 Ctrl 触发选区内联翻译，旧用户配置保留不覆盖。

## ✅ 验证

- 全量单元、UI、构建与扩展 E2E 门禁通过。
- 慢速 provider 下真实页面消息可快速返回 accepted，不等待网络完成。
- 1000 段大页面在 loading 期间可以执行恢复并清理全部扩展节点。
- 内容脚本与后台 bundle 继续满足体积预算。

## 发布说明

版本统一来自 package.json，当前为 0.13.1。Chrome Web Store 公开隐私政策、素材、审核测试页与第三方端点许可等既有上架阻断项仍需发布者处理。

## 📦 安装与升级

1. 下载本 Release 中的 `lexilayer-translator-0.13.1-chrome-web-store.zip` 并解压。
2. 在 `chrome://extensions/` 开启开发者模式，选择解压后的目录完成加载或重新加载。
3. 确认版本为 **0.13.1**，并刷新已打开网页以加载新版内容脚本。
