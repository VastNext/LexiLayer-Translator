# 语层翻译（LexiLayer Translator）0.8.0

## ✨ 新功能

- 🧩 **双渲染器**：新增内联渲染模式（Options → 渲染器模式）。内联模式在段落内部渲染译文，不向父级 flex/grid 容器新增子项，避免改变页面布局；复杂交互子树（链接、按钮、表单控件、自定义元素等）保守回退兼容模式。
- 🎛️ **渲染器选择**：新安装默认使用内联模式；升级自旧版本或导入旧配置时受控回退兼容模式，避免升级后行为突然变化。切换在下次全新页面翻译时生效，会话内的重试保持本次模式。

## 🐞 修复

- 🔗 **单链接标题内联下钻**：修复单链接标题（如 `h2 > span > a > span Releases` 配合 badge/svg/sr-only）在内联模式下被误判为不安全结构而回退兼容模式的问题；现在自动下钻至链接内安全容器，外层标题与链接节点/样式/监听器不隐藏不替换。
- 🔄 **归属翻转修复**：内联错误提示中的重试按钮不再被误判为网页交互。段落首次选用渲染器后固定归属直至恢复，loading→error→重试链中不再发生渲染器翻转。
- 🔍 **安全判定保守补强**：flex/grid 容器多子项、自定义元素（含后代）与表单控件子树（form、input、select、textarea、fieldset、output 等）一律回退兼容模式。
- ⏳ **划词加载提示**：准备提示只用于显示，不再提前标记翻译完成，也不会混入复制结果或英文译文。
- 🛡️ **偏好加载保护**：阅读偏好在加载完成前不可保存，Popup 在配置加载完成前不可发起翻译，避免使用临时默认值覆盖或绕过用户设置。

## 🏗️ 工程

- 📦 内容脚本拆分为三个常驻脚本：`content.js`（控制器库）、`content-inline.js`（内联渲染器与样式）、`content-main.js`（装配层），按 manifest 顺序注入；Popup 按需注入同步补全全部入口。
- 📏 体积预算：三个 content 相关脚本真实累计不超过 48KiB，防止拆分掩盖总量膨胀。

## 使用与限制

- 已有用户可在设置页的「阅读偏好 → 渲染器模式」主动启用内联模式；Popup 不提供渲染器切换入口。
- 此选择只影响页面翻译，不改变划词浮层或 Ctrl 划词内联翻译的渲染方式。
- 内联模式保留安全宿主的标签和样式上下文，但不保证任意嵌套 CSS 完全不受影响；复杂结构仍可能使用传统相邻插入方式。
- 开发维护说明见 `docs/architecture/renderer-maintenance.md`。
