# 语层翻译（LexiLayer Translator）0.16.0

## YouTube 双语字幕

- 在 youtube.com 视频页自动显示「原文 + 中文」双语字幕：扩展捕获播放器自身的字幕请求（携带 YouTube 颁发的访问令牌）并重放读取字幕文本，播放器内自绘双语两行，原生字幕被替换显示。
- 字幕随播放进度实时切换，支持进度拖动、倍速与暂停；广告播放期间不渲染字幕；全屏与剧场模式自动适配，字幕位置可拖动并记忆。
- 站内跳转到另一个视频时自动重建字幕会话，旧视频的翻译结果不会串扰。
- 该功能默认开启，可在「设置 → 阅读偏好 → 在 YouTube 显示双语字幕」关闭；关闭后立即恢复原生字幕（含扩展代为开启的字幕开关）。

## 字幕翻译引擎

- **YouTube 自带机翻（默认，免费）**：整段即时返回，零成本。
- **跟随当前翻译引擎**：使用页面翻译所选引擎（含自定义 AI），逐句渐进显示，复用现有批处理与缓存。
- 字幕文本只发送给所选引擎对应的服务；扩展不把字幕保存为本地文件，不提供批量下载。

## 兼容与隐私

- 无新增权限；新增两个仅匹配 youtube.com 的内容脚本（一个负责捕获播放器字幕请求，一个负责重放、翻译与渲染）。
- 字幕文本按所选引擎发送：自带机翻发往 YouTube 自身，其他引擎与页面翻译同一数据流；PRIVACY 与商店数据披露已同步。
- pot 令牌静默失败（200 空响应）、限流、无字幕轨等情况均有显式降级：保留原文行并给出状态提示，不做无限重试。

## 安装与升级

1. 下载本 Release 中的 `lexilayer-translator-0.16.0-chrome-web-store.zip` 并解压。
2. 在 `chrome://extensions/` 开启开发者模式，选择解压后的目录完成加载或重新加载。
3. 确认版本为 **0.16.0**，并刷新已打开网页以加载新版内容脚本。
