# 语层翻译（LexiLayer Translator）0.9.0

## ✨ 新功能

- ⌨️ **划词触发次数**：在设置页选择划词内联翻译需要单击、双击或三击 Ctrl / Alt / Shift / Command。
- 🛡️ **减少快捷键误触**：选择双击或三击后，单独按一次修饰键不会触发翻译，可以更安全地使用 `Ctrl+C`、`Ctrl+V` 等常用快捷键。

## 🐞 Bug 修复

- 🚦 快速连续触发时按配置累计次数，避免重复请求；超过 600 毫秒未完成下一击时自动清零。
- 🔁 重复键盘事件不计入次数，输入框、密码框和可编辑区域不响应划词内联快捷键。

## ✅ 验证

- 相关配置、Options、划词控制器测试通过。
- TypeScript 类型检查通过。
- 生产构建与内容脚本体积预算通过。
