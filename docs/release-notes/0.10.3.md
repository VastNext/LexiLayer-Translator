# 语层翻译（LexiLayer Translator）0.10.3

## 🐞 Bug 修复

- 🔄 **重试按钮点击无效**：修复在嵌套链接、卡片容器或自定义按钮内部的失败段落中，点击 ↻ 重试按钮时事件冒泡到外层父元素并被网页自身的点击拦截或路由跳转，导致无法正常触发重试的问题。现在重试按钮点击时会显式调用 `stopPropagation()` 与 `preventDefault()`，确保无论在任何复杂 DOM 环境下点击重试均能 100% 可靠触发。
