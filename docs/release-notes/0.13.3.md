# 语层翻译（LexiLayer Translator）0.13.3

## 输入框翻译状态提示

- 在 input、textarea、contenteditable 及网页 frame 中使用 `Alt+Shift+X` 成功触发选区翻译后，会在当前编辑控件附近显示“翻译中…”和加载动画。
- 提示优先显示在控件上方，空间不足时自动放到下方，并被限制在当前 frame 的可视区域内。
- 翻译完成、失败保留原文、内容或选区变化取消时，会显示短暂终态后自动移除。
- 在途重复快捷键不会重复请求；迟到的旧任务不能覆盖新任务状态。
- 提示使用 closed Shadow DOM 隔离网页样式，不写入或占用表单内容；减少动态效果偏好下停止旋转动画。

## 兼容与隐私

- 输入框翻译的数据处理行为不变：只发送用户选中的文字，不发送输入框其余内容或邻近上下文。
- 页面同步拒绝、回滚或改写译文时不会误报完成，原文和页面最终状态保持不被扩展强行覆盖。
- 浏览器管理的页面翻译快捷键、选区内联触发和旧用户配置保持不变。

## ✅ 验证

- Vitest 覆盖加载、成功、失败、取消、重复按键、旧任务隔离、宿主恢复、窄视口定位、减少动态效果和页面同步回滚。
- Chromium E2E 覆盖真实扩展中的状态提示、失败保留原文、重复按键和跨源 frame 可视定位。
- 继续运行单元测试、类型检查、生产构建、发布校验和完整 Chromium E2E 门禁。

## 安装与升级

1. 下载本 Release 中的 `lexilayer-translator-0.13.3-chrome-web-store.zip` 并解压。
2. 在 `chrome://extensions/` 开启开发者模式，选择解压后的目录完成加载或重新加载。
3. 确认版本为 **0.13.3**，并刷新已打开网页以加载新版内容脚本。
