# 语层翻译（LexiLayer Translator）0.18.0

## 设置页布局整理

- 侧栏导航、正文顺序与分区编号统一为：内置引擎、自定义 AI 引擎、AI 专家、阅读偏好、划词翻译、生词本、快捷键与触发、外观主题、数据与隐私。
- 修复生词本在导航第六项、正文却被排到第一项的问题，以及 AI 专家与自定义引擎的顺序错位。
- 统一设置分区、表单和操作按钮的排版与间距，改进窄屏布局与当前导航提示。

## 兼容性与隐私

原有设置和生词数据继续保留，无需迁移。不新增权限、第三方服务或数据收集行为。

## 安装与更新

正式发布后，下载对应 Release 中的 `lexilayer-translator-0.18.0-chrome-web-store.zip` 并解压，在 Chrome 扩展管理页加载或更新，确认版本为 **0.18.0**。

## ✅ 验证

发布门禁包括单元测试、TypeScript 类型检查、生产构建与扩展端到端测试。设置页回归覆盖导航和正文顺序、分区编号、滚动定位及桌面与窄屏布局。
