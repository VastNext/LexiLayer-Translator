# 语层翻译（LexiLayer Translator）0.10.1

## 🐞 Bug 修复

- 🛑 **父子容器重复翻译**：修复在邮件、博客等包含复合 HTML 结构的网页中，外层 `td` 或容器节点与内部多个段落 `p` 同时被选为翻译候选，导致整段内容被大包小重复翻译的问题。现在只要祖先节点包含已选取的后代段落，该祖先容器就会被正确作为冗余节点排除。
- ⏳ **页面长久停留“翻译中…”无重试按钮**：在内容脚本侧针对 `translate-batch` 请求增加 95 秒超时保护，即使发生网络僵死或消息挂起，也能自动进入失败状态并展示 ↻ 重试按钮，不再无限期等待。

## ✅ 验证

- 单元测试：37 个测试文件、571 个测试通过。
- TypeScript 类型检查通过。
- 生产构建与内容脚本体积预算通过。
