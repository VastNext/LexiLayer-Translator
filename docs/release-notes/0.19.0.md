# 语层翻译（LexiLayer Translator）0.19.0

## 输入框翻译独立设置

- 设置导航新增“输入框翻译”，位于“阅读偏好”之后；输入框目标语言不再混在阅读偏好内。
- 新增独立翻译引擎选择，默认跟随当前引擎，也可指定已启用的 Google、Bing 或自定义 AI，不改变网页翻译引擎。
- 明确指定的引擎停用或删除时提示错误，不静默切换到另一服务。
- 输入框选中文字后按 `Alt+Shift+X` 翻译并替换选区，保留既有防陈旧回填机制。

## 兼容性与隐私

旧配置默认跟随当前引擎，保留既有目标语言。独立引擎选择只保存在本地，文本仅发送给选定服务。不新增权限。

## 安装与更新

正式发布后下载 `lexilayer-translator-0.19.0-chrome-web-store.zip`，或在源码目录构建并重新加载扩展。确认版本为 **0.19.0**，然后刷新已打开的网页，使输入翻译脚本生效。

## ✅ 验证

门禁覆盖配置兼容、输入翻译引擎选择、设置导航顺序及端到端选区替换，并运行单元测试、类型检查和生产构建。
