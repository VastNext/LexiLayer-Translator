# 语层翻译（LexiLayer Translator）0.15.0

## 站内跳转自动延续翻译

- 在某个标签页发起页面翻译后，同一标签页内跳转到**同域名**页面时自动继续翻译，无需再次点击；SPA 站点的路由切换由既有动态观察器自然延续。
- 延续会保持上次翻译使用的引擎、目标语言、范围与模式；点击「显示当前页面原文」还原后立即停止延续，再次翻译会重新开始延续。
- 新增「跳转后自动延续翻译」开关（设置 → 阅读偏好，默认开启）；关闭后跳转不再自动翻译。
- 域名不同的跳转不会触发翻译；回到已启用翻译的域名时延续自动恢复。新标签页打开的链接（中键 / target=_blank）不自动翻译。
- 适用于整页加载跳转；SPA 路由切换（pushState）不会重载文档，既有动态观察器会继续翻译新增内容，无需触发延续。

## 兼容与隐私

- 延续旗标按标签页保存在 `chrome.storage.session`：仅记录当前域名与翻译命令参数（引擎、目标语言、范围、模式），浏览器关闭即清空；不写入 `chrome.storage.local`/`sync`，不记录浏览历史。
- 自动延续以用户主动发起翻译为前提，仅是同一会话的延伸；权限清单不变（无新增权限）。
- 页面控制器在翻译进度中附带命令参数供后台维护旗标；还原或关闭标签页时旗标立即清除。

## 安装与升级

1. 下载本 Release 中的 `lexilayer-translator-0.15.0-chrome-web-store.zip` 并解压。
2. 在 `chrome://extensions/` 开启开发者模式，选择解压后的目录完成加载或重新加载。
3. 确认版本为 **0.15.0**，并刷新已打开网页以加载新版内容脚本。
