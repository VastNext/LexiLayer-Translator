# 语层翻译（LexiLayer Translator）0.10.8

## 🚀 长页面翻译与重试更可靠

本次稳定性更新汇集 0.10.6–0.10.8 的修复，重点改善快速滚动、局部重试和动态网页中的翻译状态。用户已反馈：更新后的实际使用测试暂未再出现此前的问题。感谢持续提供复现步骤与验证！🙌

## 🛠️ 修复与改进

- 🔁 **重试不再打断整页翻译**：只重新提交失败段落，保留其他在途请求、排队任务和屏外等待段落，避免重试后底部一直显示“翻译中…”。
- 🛡️ **连续点击不重复入队**：重试中的段落退出失败候选，再次失败后才允许重试；旧会话未结束的重试不会锁住新会话。
- 🧹 **恢复原文不再被取消请求卡住**：即使后台取消失败或未返回，本地恢复也能完成，旧结果不会写回新会话。
- ⚡ **重新翻译复用有效缓存**：恢复原文后重新翻译，已缓存的成功译文直接复用，未完成段落重新调度，减少重复 AI 请求。
- 🧩 **动态页面占位清理**：修复原文节点移除、内部结构替换及克隆导致的旧 loading 残留，校验译文实际挂载关系。
- 📊 **进度与任务身份校验**：成功、失败及缺失结果按当前任务与版本处理，减少旧结果污染新进度的情况。
- ↩️ **错误入口可恢复**：内联段落在请求期间变成不安全结构时，回退到兼容渲染器显示错误与重试按钮。
- 🔇 **消除进度广播未处理异常**：Popup 关闭、没有消息接收端时，不再因进度通知产生未处理的 Promise 拒绝。

## 📦 安装与升级

1. 下载本 Release 中的 `lexilayer-translator-0.10.8-chrome-web-store.zip` 并解压。
2. 在 `chrome://extensions/` 开启开发者模式，使用“加载已解压的扩展程序”选择解压后的目录；已有安装可更新原目录后点击“重新加载”。
3. 确认版本为 **0.10.8**，再刷新需要翻译的网页，以清除旧内容脚本和页面状态。

ZIP、SHA-256 校验文件与发布说明由 GitHub Actions 从干净检出构建生成。🔐
